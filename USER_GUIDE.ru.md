# Руководство пользователя WebCodex: Простое подключение агентов за 3 шага 🚀

Это руководство объясняет, как за 2 минуты создать нового агента, запустить его на рабочем компьютере и подключить к ChatGPT без ручной возни с токенами.

---

## 🎯 Вся схема в двух словах:
1. В **Админке** нажимаем «Создать» и скачиваем готовый `.bat` файл.
2. На **компьютере** кладем этот `.bat` рядом с `webcodex-agent.exe` и запускаем.
3. В **ChatGPT** вставляем 5 готовых строчек параметров.

---

## 📋 Шаг 1. Создание агента в Админке

1. Откройте в браузере: **`https://codex.grom.world/admin`**
2. Введите имя пользователя и пароль администратора.
3. В блоке **«Добавить нового агента»**:
   - **ID агента**: латинскими буквами без пробелов (например: `home`, `work`, `laptop`).
   - **Название**: любое понятное имя (например: `Мой домашний ПК`).
   - Нажмите кнопку **«Создать агента»**.

4. На открывшейся странице нажмите большую зеленую кнопку:
   👉 **`📥 Скачать start-agent-<id>.bat`**
   *(Файл сохранится в папку «Загрузки» на вашем компьютере)*.

---

## 💻 Шаг 2. Запуск на рабочем компьютере (Windows)

1. Создайте на компьютере любую папку (например, `C:\WebCodex`).
2. Положите в эту папку **два файла**:
   - `webcodex-agent.exe` *(исполняемый файл агента)*
   - `start-agent-<id>.bat` *(файл, который вы скачали в Шаге 1)*
3. **Дважды кликните по файлу `start-agent-<id>.bat`**.

> 🎉 **Готово!** Откроется черное окно консоли. В панели управления `/admin` статус вашего агента сразу сменится на **`🟢 ONLINE`**.

---

## 🤖 Шаг 3. Подключение к ChatGPT Web

*Делается один раз для каждого рабочего компьютера.*

1. Откройте ChatGPT в браузере: [chatgpt.com](https://chatgpt.com).
2. Перейдите в **Настройки (Settings) ➔ Connected Apps (Связанные приложения)** или откройте настройки вашего **Custom GPT / Action**.
3. Заполните поля (все значения можно скопировать кнопкой **📋** прямо со страницы создания агента или из скачанного файла `chatgpt-oauth-<id>.txt`):

| Поле в ChatGPT | Значение для вставки |
| :--- | :--- |
| **Server URL** | `https://codex.grom.world/mcp` |
| **Authorization URL** | `https://codex.grom.world/oauth/authorize` |
| **Token URL** | `https://codex.grom.world/oauth/token` |
| **Client ID** | `wc_client_...` *(нажмите 📋 «Скопировать» в админке)* |
| **Client Secret** | `wc_oauth_...` *(нажмите 📋 «Скопировать» в админке)* |
| **Auth Type** | `OAuth 2.0` *(Authorization Code + PKCE)* |

4. Нажмите **Connect / Войти**. ChatGPT перенаправит вас на шлюз, моментально получит доступ и вернется обратно.

---

## ❓ Частые вопросы

#### Что если я забыл или потерял ключи?
В целях безопасности сами секретные ключи не хранятся на сервере в открытом виде. Если вы потеряли ключ — просто зайдите в админку в карточку агента, нажмите **«Ротировать Agent Token»** или **«Ротировать OAuth Secret»**, и система сгенерирует новый `.bat` файл в 1 клик.

#### Как подключить второй компьютер (например, рабочий ноутбук)?
1. В админке создайте агента с ID `work`.
2. Скачайте `start-agent-work.bat`.
3. Запустите его на рабочем ноутбуке.
4. Оба компьютера будут работать одновременно и независимо!
